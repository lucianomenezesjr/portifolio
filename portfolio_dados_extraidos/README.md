# Dados extraídos do portfólio

Esta pasta reúne os dados informacionais encontrados em `portifolio-main.zip`. A análise foi limitada a conteúdo, arquivos, textos, projetos, competências, experiências, contatos e mídias; não contém avaliação visual de design.

## Onde encontrar

- `dados_consolidados.md`: consolidação dos dados do site e dos currículos.
- `documentos/`: PDFs originais dos currículos em português e inglês.
- `documentos_texto/`: texto extraído dos dois PDFs.
- `midias/`: cópias organizadas das fotos de perfil e imagens dos projetos.
- `portifolio-main/portifolio-app/`: código-fonte e arquivos do projeto, sem `node_modules`.
- `inventario/`: listas e metadados auxiliares.

## Observações

- O site possui conteúdo em português e inglês; ambos foram preservados na fonte e resumidos no relatório.
- O currículo contém projetos, experiência e certificações adicionais aos três projetos apresentados na seção principal do site.
- O formulário de contato contém um webhook do Discord hardcoded no código-fonte original. Ele não foi reproduzido no relatório por segurança; está preservado apenas no arquivo original correspondente.
