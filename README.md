# Portfólio — Luciano Menezes

Portfólio em React + TypeScript, servido e empacotado com [Vite](https://vite.dev/).

## Desenvolvimento

```bash
npm install
npm run dev
```

O app fica disponível em `http://localhost:5173`.

## Build de produção

```bash
npm run build
npm run preview
```

Os componentes ficam em `src/App.tsx`, os tipos e dados em `src/data.ts` e `src/portfolioData.ts`, e os estilos continuam em `style.css`. Para baixar as imagens referenciadas pelos projetos, execute `node download-assets.mjs`.
